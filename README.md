# 🏝️ 八丈タウンアプリ（試作評価版）

八丈島の暮らしに役立つ情報を、スマートフォンひとつにまとめた **Android用の試作アプリ**です。

> ⚠️ **非公式の試作アプリです。** 八丈町および八丈町議会が運営・公認するものではなく、個人による独立した取り組みです。
> 災害時は、町や気象庁などの公式発表を確認してください。

## 📲 ダウンロード

- **[最新版のAPKをダウンロード](https://github.com/nazmard/hachijo-town-app/releases/latest/download/app-debug.apk)**
- [リリースの詳細・変更点](https://github.com/nazmard/hachijo-town-app/releases/latest)
- [配布ページ](https://nazmard.github.io/hachijo-town-app/)

Android専用です。iPhone（iOS）には、いまは対応していません。

### インストールのしかた

1. 上の「最新版のAPKをダウンロード」を押します。
2. ダウンロードが終わったら、通知か「ダウンロード」の中のファイルを開きます。
3. 「提供元不明のアプリ」の許可を求められたら、いま使っているブラウザに許可して、もう一度ファイルを開きます。
4. 「インストール」を押します。

以前の版が入っているときは、先にアンインストールしてから入れてください。「更新できません」と出ることがあります。試作版（デバッグ版）のため、インストール時に安全性の確認の画面が出ることがあります。

## 🏝️ できること

| 画面 | 内容 |
|---|---|
| ホーム | 町の公式サイト、防災情報、よく使う町のサービス（行政手続き、町営バス、町立病院、健康・福祉、子育て・教育、施設、温泉混雑情報、ホエールカメラ）への入口、天気 |
| お知らせ | 町の新着情報、防災・安全情報への入口 |
| 交通 | 東海汽船（船）とANA（飛行機）の運航状況を、公式ページですぐに確認 |
| ごみ出し | 地区を選んで、今日・明日に出せるごみを表示 |
| 議員紹介 | 町議会議員の一覧、SNS（Xアプリで開きます）、議会映像（町公式）への案内 |

各画面に「戻る」ボタンがあり、戻ったときは、前に見ていた位置を表示します。

## ⚠️ ご利用にあたって

- ごみの収集曜日、議員の氏名表記は**暫定**です。町の公式情報で確認してください。
- 運航状況・天気は、天候などで変わります。出発前に、各社の公式ページで確認してください。
- 天気は予報モデルによる**参考表示**で、気象庁の公式予報ではありません。警報・注意報は気象庁で確認してください。
- インストールは自己責任でお願いします。

## 🛠️ 開発者向けメモ

### フォルダの構成

| 場所 | 役割 |
|---|---|
| `index.html`（一番上） | APKを配る**配布ページ**（GitHub Pagesで公開） |
| `app/src/main/assets/index.html` | **アプリの画面そのもの**（ホーム・お知らせ・交通・ごみ出し・議員紹介） |
| `app/src/main/java/jp/hachijo/townapp/MainActivity.kt` | WebViewの設定、Xアプリで開く処理、画面の余白 |
| `app/src/main/res/` | アプリのアイコン（`mipmap-*`） |
| `app/build.gradle.kts` | 版番号（`versionCode`、`versionName`） |
| `.github/workflows/` | APKを自動でビルドする設定 |

2つの `index.html` は別のファイルです。どちらも消さないでください。

### 更新の流れ

1. `app/src/main/assets/index.html` などを編集して、「Commit changes」を押します。
2. 「Actions」で、ビルドが緑のチェックになるのを待ちます。
3. 実行の画面の「Artifacts」から、APKをダウンロードして解凍します。
4. 版番号を上げて（`app/build.gradle.kts`）、「Releases」で新しいリリースを作り、APKを添付します。

### 注意

- `res` フォルダの中に、zipや、別のフォルダ（`res/res` など）を置くと、ビルドが失敗します。
- `res` の中の画像は、決まった名前のフォルダ（`mipmap-hdpi` など）に置きます。
